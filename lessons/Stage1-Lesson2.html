Step 1
こそあど全体体系表 ＆ イラスト図解 — Ko-So-A-Do System
Japanese demonstratives follow a beautifully unified 4-way pattern: こ (near me), そ (near you), あ (far from both), and ど (question). Today in Lesson 2, we master the "things" columns!
イラストで理解！ クマの田中さんと白ウサギの鈴木さんで見る「これ・それ・あれ」の距離感
Tanaka-san (Bear / Speaker) and Suzuki-san (Rabbit / Listener) show you how distance decides which word to use:
📗 これ こ (Near Me)
話し手（クマの田中さん）の近く
手元や自分の目の前にある物を指すとき。
例：これは本です。
📘 それ そ (Near You)
聞き手（ウサギの鈴木さん）の近く
話し相手の手元や相手の前にある物を指すとき。
例：それは本です。
📙 あれ あ (Far from Both)
二人から離れた場所（遠く）
話し手からも聞き手からも離れた遠くの物を指すとき。
例：あれは本です。

Grammar 1
これ／それ／あれ は N です — This / That / That over there is N
Demonstrative pronouns stand alone to point at things based on their distance from the speaker and listener.
基本公式これ／それ／あれ ＋ は ＋ [名詞] です。
これ
near speaker
+
は
topic
+
辞書
noun
+
です。
is
Examples（身の回りのもの）
1
これは辞書じしょです。
This is a dictionary.
2
それはノートですか。
Is that (near you) a notebook?
3
あれは時計とけいじゃありません。鞄かばんです。
That over there is not a watch. It is a bag.
4
これも私わたしの傘かさです。
This is also my umbrella.
Drill 1
Practice: これ／それ／あれ
1-1. This is a magazine. (これ / 雑誌)
これは雑誌ざっしです。
1-2. Is that (near you) a newspaper? (それ / 新聞)
それは新聞しんぶんですか。
1-3. That over there is a key. (あれ / 鍵)
あれは鍵かぎです。
1-4. This is not a pen. It is a pencil. (これ / ペン / 鉛筆)
これはペンじゃありません。鉛筆えんぴつです。
Grammar 2
この／その／あの ＋ 名詞 — This / That / That Noun over there
Use この / その / あの directly before a noun. They cannot stand alone like pronouns!
イラストで直感理解！ 「この本」「その本」「あの本」の使い分け
See how the bear (Tanaka-san) and the bunny (Suzuki-san) refer to each specific book:
📖 この本 (This book)
話し手（田中さん）の手元にある本
「この本は私のです」
📖 その本 (That book)
聞き手（鈴木さん）の手元にある本
「その本は鈴木さんのですか」
📖 あの本 (That book over there)
二人から離れたスツールの上にある本
「あの本は誰のですか」
公式[ この／その／あの ＋ 名詞 ] は 〜です。
Examples
1
この本ほんは私わたしのです。
This book is mine.
2
その鞄かばんは鈴木すずきさんのですか。
Is that bag (near you) Suzuki's?
3
あの傘かさは私わたしのじゃありません。
That umbrella over there is not mine.
Drill 2
Practice: この／その／あの ＋ 名詞
2-1. This pen is Tanaka's. (このペン / 田中さん)
このペンは田中たなかさんのです。
2-2. Is that magazine (near you) yours? (その雑誌 / あなた)
その雑誌ざっしはあなたのですか。
2-3. That watch over there is my father's. (あの時計 / 私の父)
あの時計とけいは私わたしの父ちちのです。
2-4. This dictionary is not mine. (この辞書 / 私)
この辞書じしょは私わたしのじゃありません。
Grammar 3
N1 の N2 ＆「〜の」による名詞の省略 — Possession & Noun Replacement
The particle の links nouns ("Tanaka's umbrella"). When the context is clear, の can stand for the noun itself ("mine", "Suzuki's").
ポイント名詞の繰り返しを防ぐ「〜の」（＝〜のもの）
私の本です
Full sentence
➔
私のです
Short / Natural ("It's mine")
Examples
1
これは田中たなかさんの傘かさです。
This is Tanaka's umbrella.
2
このノートは鈴木すずきさんのです。
This notebook is Suzuki's.
3
その鍵は私わたしのじゃありません。
That key is not mine.
Drill 3
Practice: 〜の
3-1. It is mine. (私 / の)
私わたしのです。
3-2. This is my mother's bag. (これ / 私の母 / 鞄)
これは私わたしの母ははの鞄かばんです。
3-3. That watch is not Tanaka's. (その時計 / 田中さん)
その時計とけいは田中たなかさんのじゃありません。
3-4. Is that over there Suzuki's? (あれ / 鈴木さん)
あれは鈴木すずきさんのですか。
Grammar 4
だれ・何・どれ・どの＋名詞 — Question Words for Things & Owners
Ask "What is this?", "Whose is this?", "Which one?", and "Which book?" using specific question words.
イラストで直感理解！ 「どれ？」「どの本？」と選ぶクマの田中さん
Tanaka-san is wondering which one is Suzuki's book among the three books:
❓ どれ (Which one - Standalone)
3つ以上の選択肢から「どれ」と選ぶとき
「鈴木さんの本はどれですか」
❓ どの本 (Which book - with Noun)
「どの＋名詞」で具体的にたずねるとき
「どの本が鈴木さんのですか」
疑問詞まとめLesson 2の4大疑問表現
疑問表現 意味 (English) 質問の例 答えの例
何（なん） What これは何ですか。 それは辞書です。
だれ（誰） Who これはだれの傘ですか。 私のです。
どれ Which one あなたの鍵はどれですか。 これです。
どの＋名詞 Which [noun] どの鞄ですか。 その鞄です。
Examples
1
これは何なんですか。
What is this?
➔ それは手帳てちょうです。
2
あれはだれの鞄かばんですか。
Whose bag is that over there?
➔ 田中たなかさんの鞄かばんです。
3
あなたの鍵かぎはどれですか。
Which one is your key?
➔ これです。
Drill 4
Practice: だれ・何・どれ・どの
4-1. What is that (near you)? (それ / 何)
それは何なんですか。
4-2. Whose pen is this? (これ / だれ / ペン)
これはだれのペンですか。
4-3. Which one is Tanaka's watch? (田中さんの時計 / どれ)
田中たなかさんの時計とけいはどれですか。
4-4. Which umbrella is yours? (どの傘 / あなた)
あなたの傘かさはどの傘かさですか。
Step 6
これまでの総復習 — Comprehensive Dialogue & Drill
Tanaka-san and Suzuki-san practice demonstratives and possession together. Test yourself with 2 drill questions per grammar point!
Dialogue
誰の傘ですか — Whose Umbrella Is This? (田中 & 鈴木)
田中（クマ）
鈴木すずきさん、これは何なんですか。
Suzuki, what is this?
鈴木（ウサギ）
それは傘かさです。
That is an umbrella.
田中（クマ）
鈴木すずきさんの傘かさですか。
Is it your umbrella, Suzuki?
鈴木（ウサギ）
いいえ、そうじゃありません。私わたしのじゃありません。
No, that's not right. It is not mine.
田中（クマ）
では、この本ほんも鈴木すずきさんのじゃありませんか。
Then, is this book also not Suzuki's?
鈴木（ウサギ）
あ、その本ほんは私わたしのです！私わたしの辞書じしょです。ありがとうございます！
Ah, that book is mine! It is my dictionary. Thank you!
