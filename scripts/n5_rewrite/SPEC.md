# N5 全面精査・書き直し 共通仕様 (SPEC)

リポジトリ: /Users/yamauchimiku/Documents/GitHub/japanese-learning  （以下 REPO）
Python3 のみ（node は無い）。ふりがな生成ライブラリ: `scripts/n5_rewrite/n5_lib.py`（Janome ベース + 手動検証済み補正）。

## 0. 状況
N5 のデータは機械生成のテンプレ文・でたらめ問題だらけ（例:「先生や友達と一緒に、上手について楽しく勉強しました」「暑い視点を持って」、
語彙クイズで answer インデックスと説明の正解が食い違う、文法問題「毎日楽しくですだ話します」など）。
**既存の文・問題はほぼ使えない前提で、日本語ネイティブ校閲者の目で 1 文ずつ、完全オリジナルで書き直す。**
既存の良い文（自然で正確なもの）は流用してよいが、必ず自分で読んで確認すること。

## 1. 絶対ルール（違反ゼロ）
1. **自然な日本語**: 翻訳調・コロケーション不自然・助詞誤用・不要な「私は」連発・不自然な丁寧体混在をゼロに。母語話者が1ミリも引っかからない文だけ。
2. **N5 レベル**: 語彙・文法は N5（初級前半、〜30課程度）の範囲を基本とする。N5 範囲外の漢字語を例文に入れない（入れる場合は必ずふりがなが付く）。
3. **正解が1つに定まる**: 穴埋め・用法・類義語問題は「文脈が足りずどれでも入る」を完全排除。状況を限定する前提文（例: 「A: 今、何をしていますか。B: 本を（　　　）。」）を付け、
   **4つの選択肢を1つずつ空欄に入れて自分で検証**し、不正解の3つが文法的／意味的／文脈的に明確に誤りであることを確認する。
4. **ダミー選択肢の質**: 同品詞・同水準・紛らわしいもの。カタカナ語の無関係混入（パスタ、ラーメン…を助詞問題に）禁止。
5. **ふりがな**: 必ず `R()` を使う。曖昧な漢字は `{漢字|よみ}` で明示。下記の読みを 100% 守る。
   - 「この後」「その後」「食べた後」「後で」= **あと**（のち/ご にしない）
   - カ変動詞「来る」: 来ない・来なければ・来なかった = **こ**、来ます・来た・来て = **き**、来る = **く**
   - 一日（いちにち／ついたち）、辛い（から／つら）、開く（あ／ひら）、何人（なんにん）、何（なに／なん）、空（あ／す／そら／から）、方（かた／ほう）、
     生（う／なま／せい）等は文脈で判定して明示（`R()` は明示が無いと例外を出す）。
   - 1人・2人は {一人|ひとり}・{二人|ふたり}、20歳 は {二十歳|はたち}、1日は {一日|いちにち}/{一日|ついたち}。算用数字＋助数詞（10時・15分・3日…）は R() が自動処理。
6. **センシティブ表現ゼロ**: 政治・政党・政治家・歴史・戦争・領土・国際摩擦・犯罪・暴力・いじめ・差別・宗教・事故死傷、
   登場人物（田中さん・鈴木さん等）への否定的／攻撃的描写（ケチ・嘘つき・嫌われている等）を一切書かない。題材は日常・学校・仕事・買い物・料理・天気・家族・旅行・趣味・健康など前向きで温かいもの。
7. **著作権**: 他教材・過去問・Web 文の引き写し禁止。「公式」「〇〇問題集準拠」等、他教材名の言及は一切禁止。完全オリジナル。
8. **空欄表記**: 必ず `（　　　）`（全角括弧＋全角スペース3つ）。「？」「空欄」「（する）」を入れない。`reading` には「（する）」を入れない。
9. 英語訳は自然な英語（直訳調・"I became able to to sit well" のような破綻を禁止）。
10. 同じ文・同じ型の使い回し禁止（テンプレ量産しない）。1つ1つ違う場面・違う文。

## 2. 作業のやり方
- 自分の担当ファイルだけを編集する。**git commit / git add / git checkout / git stash は絶対にしない**（最後に親エージェントがまとめて行う）。
- 他レベル（N1〜N4）・他ファイル・`secrets/`・`audio/` は触らない。MP3 の再生成もしない。
- データは Python のデータファイルに手書きし、ビルダースクリプトで JS に出力（再現可能に）。ビルダーは `n5_lib.py` を import。
- ふりがなは出力後に必ず目視レビュー: 全ルビペア（漢字→読み）を一覧出力して、すべて文脈に合っているか確認し、誤りは `{漢字|よみ}` で修正。
- 最後に自己検証スクリプトを走らせ、結果を報告: 構文OK / ルビ漏れ（`lint_ruby`）ゼロ / `choices[answer]==correct_text` / 選択肢重複なし / センシティブ語ゼロ。
- 完了時、親エージェントに送るメッセージは簡潔に（直した主な内容・件数・残課題）。長文の貼り付け不要。

## 3. n5_lib.py の使い方
```python
import sys; sys.path.insert(0, '/Users/yamauchimiku/Documents/GitHub/japanese-learning/scripts/n5_rewrite')
from n5_lib import R, P, lint_ruby, place_choices, balanced_targets, balanced_targets_by_group, sensitive_hits, write_js
R("{明日|あした}は友達と一緒に来なければなりません。")  # -> <ruby>明日<rt>あした</rt></ruby>は<ruby>友達<rt>ともだち</rt></ruby>と...
P(html)                 # ルビ・タグ・{x|y} を除いたプレーン文字列
lint_ruby(html)         # <ruby> の外にある漢字のリスト（空であるべき）
```
`<u>…</u>` `<strong>…</strong>` `<br>` 等のタグはそのまま通る。`python3 scripts/n5_rewrite/n5_lib.py` で動作例が出る。
