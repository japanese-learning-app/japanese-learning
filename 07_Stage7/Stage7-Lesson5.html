Grammar A 誰だれかが目的もくてきを持もって行いった結果けっかの状態じょうたい：［対象］が ＋ ［他動詞て形］＋ あります
In Lesson 4, you learned 「［対象］が ＋ ［自動詞て形］＋ います」 (e.g., 『窓が開いています』 = The window is open [simple objective state]). Now compare that with **「［対象］が（／は） ＋ ［他動詞て形］＋ あります」** (e.g., 『窓が開けてあります』)! Why use a Transitive Verb (他動詞) with 「あります」 and particle **「が」**? Because it expresses that **SOMEONE intentionally performed the action for a specific purpose (or as preparation), and that resulting state is currently in place**! Compare the 3-way system: (1) 『窓が開いています』 (Auto + います = The window is open [neutral observation]). (2) 『窓が開けてあります』 (Trans + あります = The window has been opened [by someone on purpose, e.g., to air out the room] / It is already prepared!). (3) 『ホテルが予約してあります』 = The hotel has already been booked (preparation is complete)!
［対象］が（／は）
カレンダーが ／ ホテルが（※「を」→「が」に変化へんか！）
＋
他動詞たどうして形かたち
貼はって ／ 予約よやくして ／ 開あけて
＋
あります（意図いと的てきな準備じゅんび結果けっか）
誰だれかが目的もくてきを持もってした状態じょうたい！
［場所］に ［対象］が ［他動詞て形］＋ あります （※元々もともとの「対象たいしょうを」が「対象たいしょうが／は」になる！）
誤用 (Incorrect) ✕ 壁かべにポスターが貼はっています。 ／ ✕ 机つくえの上うえに花はなが飾かざられます。
「貼はる・飾かざる・書かく・並ならべる・予約よやくする」は他動詞たどうしなので、結果けっか状態じょうたいはすべて「〜てあります」にします！
貼る, 飾る, 書く, and 予約する are transitive verbs! To describe the resulting state ('is posted / is displayed / is written'), use 〜てあります (not 〜ています).
正解 (Correct) ⭕ 壁かべにポスターが貼はってあります。 ／ 机つくえの上うえに花はなが飾かざってあります。
誰だれかが貼はった・飾かざった・書かいた結果けっかがそこにあるときは「［対象］が＋他動詞たどうして形かたち＋あります」です。
When something is posted, displayed, written, or prepared by someone, use [Object] が + Transitive Te-form + あります.
Examples
1
壁かべに今月こんげつの予定よてい表ひょうが貼はってあります。
This month's schedule chart is posted on the wall (someone put it up on purpose).
2
このノートには大事だいじな言葉ことばと意味いみが書かいてあります。
Important words and meanings are written in this notebook.
3
来週らいしゅうの京都きょうと旅行りょこうは、もう新幹線しんかんせんの切符きっぷもホテルも予約よやくしてありますから、安心あんしんしてください。
For next week's trip to Kyoto, both the Shinkansen tickets and the hotel have already been booked, so please rest assured!
Drill A
即応そくおうドリル A：意図いと的てきな結果けっか状態じょうたい「［他動詞］てあります」（全ぜん5問もん）
A-1. Describe the state: 'Pretty flowers are displayed on the table.' (花はなを飾かざります → 花はなが〜てあります)
テーブルの上うえにきれいな花はなが飾かざってあります。
※ 飾ります (transitive) → 花が 飾ってあります。
A-2. Describe the state: 'Mr. Tanaka's name is written on the bag.' (名前なまえを書かきます → 名前なまえが〜てあります)
かばんに田中たなかさんの名前なまえが書かいてあります。
※ 書きます (transitive) → 名前が 書いてあります。
A-3. Describe the state: 'Chairs and desks are arranged in the meeting room.' (椅子いすと机つくえを並ならべます → 〜てあります)
会議かいぎ室しつに椅子いすと机つくえが並ならべてあります。
※ 並べます (transitive) → 椅子と机が 並べてあります。
A-4. Reassure your friend: 'Cold beer has already been bought (and is ready in the fridge).' (ビールを買かいます → 〜てあります)
もう冷つめたいビールが買かってありますよ。
※ 買います → ビールが 買ってあります (already bought in preparation).
A-5. Contrast with Lesson 4: Say 'The window has been opened (on purpose by someone to air out the room).' (窓まどを開あけます → 〜てあります)
窓まどが開あけてあります。
※ 窓が開いています = simply open (auto); 窓が開けてあります = opened on purpose by someone (trans)!
Grammar B 「［動詞て形］＋ おきます（カジュアル：〜とく）」の3大だい用法ようほう（①事前じぜんの準備じゅんび ②事後じごの片付かたづけ ③そのまま維持いじ）
While 「〜てあります」 describes a COMPLETED state of preparation, **「［対象］を ＋ ［動詞て形］＋ おきます」** describes the **INTENTIONAL ACTION** of doing something in advance for a future purpose! It has THREE essential meanings: (1) **Advance Preparation (事前の準備)**: 『旅行の前にホテルを予約しておきます』 (I will book a hotel in advance before the trip). (2) **Post-Event Cleanup / Measure (事後の措置)**: 『食事が終わったら、お皿を洗っておきます』 (Once the meal is over, I'll wash the dishes so they're clean for next time). (3) **Leaving Something As It Is (そのままの維持・放置)**: 『まだ使いますから、電気をつけておいてください / 消さないでおいてください』 (Please leave the light on / leave it without turning it off). CASUAL CONTRACTION: In daily conversation, 「〜ておく」 becomes **「〜とく」** (買っておく → 買っとく) and 「〜でおく」 becomes **「〜どく」** (読んでおく → 読んどく)!
① 事前じぜんの準備じゅんび
切符きっぷを買かっておきます（買かっとく）
／
② 事後じごの片付かたづけ
元もとの場所ばしょに戻もどしておきます
／
③ そのまま維持いじ
窓まどを開あけておいてください（そのままに！）
［対象］を ＋ ［動詞て形］＋ おきます ／ 否定ひてい維持いじ：［ない形］＋ でおきます （カジュアル：〜とく ／ 〜どく）
誤用 (Incorrect) ✕ パーティーの前まえに飲み物のみものが買かっておきます。 ／ ✕ もうホテルを予約よやくしておきます（完了かんりょう状態じょうたいの報告ほうこく）。
①「〜ておきます」はこれからの準備じゅんび行動こうどうなので目的もくてき語ごは「を」です。②すでに予約よやく済ずみの状態じょうたいは「予約よやくしてあります」です。
(1) 〜ておきます is a transitive action, so the object takes を (飲み物を買っておきます). (2) To report that it is ALREADY booked, use ホテルが予約してあります!
正解 (Correct) ⭕ 今いまから飲み物のみものを買かっておきます（行動こうどう）。 → もう飲み物のみものが買かってあります（完了かんりょう状態じょうたい）。
「これから準備じゅんびする行動こうどう＝を〜ておきます」と「すでに準備じゅんびしてある状態じょうたい＝が〜てあります」を対比たいひで覚おぼえましょう。
Action of preparing in advance = N を 〜ておきます; Resulting state of being already prepared = N が 〜てあります.
Examples
1
明日あしたの会議かいぎの前まえに、資料しりょうを読よんでおいてください。（事前じぜんの準備じゅんび）
Before tomorrow's meeting, please read the handout in advance.
2
ハサミを使つかったら、元もとの引き出ひきだしに戻もどしておいてください。（事後じごの措置そち）
Once you finish using the scissors, please put them back in the original drawer.
3
もうすぐお客きゃくさんが来きますから、エアコンをつけておきましょう。（そのまま維持いじ）
The guests will arrive soon, so let's leave the air conditioner on.
Drill B
即応そくおうドリル B：事前じぜん準備じゅんび・事後じご措置そち・放置ほうち「〜ておきます」（全ぜん5問もん）
B-1. Say: 'Before the trip, I will exchange money in advance.' (お金かねを換かえます → 〜ておきます)
旅行りょこうの前まえに、お金かねを換かえておきます。
※ 換えます → 換えて ＋ おきます (advance preparation).
B-2. Say: 'Before the guests arrive, let's clean the room in advance.' (部屋へやを掃除そうじします → 〜ておきましょう)
お客きゃくさんが来くる前まえに、部屋へやを掃除そうじしておきましょう。
※ 掃除して ＋ おきましょう。
B-3. Ask someone to leave the window as it is: 'Because it is hot, please leave the window open.' (窓まどを開あけます → 〜ておいてください)
暑あついから、窓まどを開あけておいてください。
※ 開けて ＋ おいてください = Please keep/leave it open.
B-4. Ask someone NOT to clear away the dishes yet: 'Because I am still eating, please leave it as it is (without clearing it away).' (そのままにします → 〜ておいてください)
まだ食たべていますから、そのままにしておいてください。
※ そのままにしておいてください is the most useful phrase for 'Please leave it as it is!'.
B-5. Say in casual Japanese using 〜とく: 'I'll buy the drinks in advance!' (飲み物のみものを買かっておくね)
飲み物のみものを買かっとくね！
※ 買っておく contracts to 買っとく in casual speech!
Grammar C 完了かんりょうと未み完了かんりょうの対比たいひ：「もう 〜ました」 vs 「まだ［動詞て形］＋ いません」
When someone asks a completion question with 「もう 〜ましたか」 ('Have you already done ~?'), how do you answer 'Not yet'? In Stage 2, beginners learn the short reply 『いいえ、まだです』. However, when you want to state the full verb ('No, I haven't eaten yet / It hasn't been decided yet'), you MUST use **「まだ ＋ ［動詞て形］＋ いません」** — NEVER 『✕ まだ食べませんでした』! Why? Because 『食べませんでした』 means a past opportunity is completely over and you didn't eat (e.g., yesterday), whereas 『まだ食べていません』 means you are currently in the state of 'not having eaten YET (and will eat soon)'!
質問しつもん：もう 〜ましたか
もう昼ひるご飯はんを食たべましたか
→
はい、もう 〜ました
はい、もう食たべました（完了かんりょう）
／
いいえ、まだ 〜ていません
いいえ、まだ食たべていません（未み完了かんりょう！）
Q：もう 〜ましたか。 → はい、もう 〜ました。 ／ いいえ、まだ ［動詞て形］＋ いません。（短縮たんしゅく：いいえ、まだです）
誤用 (Incorrect) ✕ A：「もう昼ひるご飯はんを食たべましたか。」 B：「いいえ、まだ食たべませんでした ／ まだ食たべません。」
「まだ（未み完了かんりょう）」には「〜ませんでした」も「〜ません」も使つかえません！必かならず「まだ〜ていません」にします。
Never say まだ食べませんでした or まだ食べません for 'I haven't eaten yet'! Always use まだ食べていません.
正解 (Correct) ⭕ A：「もう昼ひるご飯はんを食たべましたか。」 B：「いいえ、まだ食たべていません。」
未み完了かんりょうは常つねに「まだ ＋ 動詞どうして形かたち ＋ いません」で表あらわします。
Unfinished actions ('not yet') are always expressed with まだ ＋ Te-form ＋ いません.
Examples
1
A：「来月らいげつの飛行機ひこうきのチケットはもう買かいましたか。」 B：「いいえ、まだ買かっていません。今日きょう買かっておきます。」
A: 'Have you already bought next month's plane ticket?' B: 'No, I haven't bought it yet. I'll buy it in advance today.'
2
9月つきになりましたが、昼間ひるまはまだ涼すずしくなっていません。
It has become September, but it hasn't gotten cool during the daytime yet.
3
引っ越ひっこしの荷物にもつが多おおすぎて、まだ全部ぜんぶ片付かたづいていません。
There are too many moving boxes, so they haven't all been tidied up yet.
Drill C
即応そくおうドリル C：完了かんりょうと未み完了かんりょう「もう〜ました vs まだ〜ていません」（全ぜん5問もん）
C-1. Answer 'Have you already read this newspaper?' negatively: 'No, I haven't read it yet.'
いいえ、まだ読よんでいません。
※ 読みます → まだ読んでいません (never まだ読みませんでした!).
C-2. Answer 'Has the bank closed already?' negatively: 'No, it hasn't closed yet (it's still open).'
いいえ、まだ閉しまっていません。
※ 閉まります → まだ閉まっていません。
C-3. Say: 'Next week's schedule has not been decided yet.' (決きまります → まだ〜ていません)
来週らいしゅうの予定よていはまだ決きまっていません。
※ 決まります → まだ決まっていません。
C-4. Answer 'Has the rain stopped already?' negatively: 'No, it hasn't stopped yet.' (雨うがやみます → まだ〜ていません)
いいえ、まだやんでいません。
※ やみます → まだやんでいません。
C-5. Answer 'Did Mr. Nakamura arrive already?' negatively: 'No, he hasn't arrived yet.' (着つきます → まだ〜ていません)
いいえ、まだ着ついていません。
※ 着きます → まだ着いていません。

💡 「窓まどが開あいています」と「窓まどが開あけてあります」と「窓まどを開あけておきます」の1分ふんストーリー
①これから友達ともだちが来くるので、換気かんきのために私わたしが『窓まどを開あけておきます』（準備じゅんびの行動こうどう）。②10分ふん後ご、部屋へやに入はいってきた鈴木すずきさんが見みて、「あ、涼すずしいですね。『窓まどが開あけてありますね』（誰だれかが目的もくてきを持もって開あけてくれた結果けっか状態じょうたい）」と言いいます。③一方いっぽう、朝あさ起おきたら風かぜで勝手かってに開あいていた場合ばあいは『窓まどが開あいています』（自動詞じどうしの単たんなる状態じょうたい）と言いいます！
(1) Friends are coming soon, so to air out the room I say: 『窓を開けておきます』 (Action: I'll open the window in advance). (2) Ten minutes later, Ms. Suzuki walks in and notices: 『窓が開けてありますね』 (State: Someone has opened the window on purpose!). (3) If you simply notice a window is open without thinking about anyone's purpose, you say: 『窓が開いています』!

手帳てちょうに今日きょうの予定よていが書かいてあります。
※ 予定が ＋ 書いてあります。

テーブルの上うえにお皿さらとお箸はしが並なべてあります。
※ お皿とお箸が ＋ 並べてあります。

授業じゅぎょうが始はじまる前まえに、単語たんごを調しらべておきます。
※ 単語を ＋ 調べておきます (action of preparing).
R-5. State a post-use action: 'When you finish using the dictionary, please put it back in its original place.' (元もとの場所ばしょに戻もどします → 〜ておいてください)
辞書じしょを使つかったら、元もとの場所ばしょに戻もどしておいてください。
※ 戻して ＋ おいてください。

ニュースを見みていますから、テレビをつけておいてください。
※ つけて ＋ おいてください (keep it on).
R-7. Answer 'Have you already cleaned your room?' negatively: 'No, I haven't cleaned it yet.'
いいえ、まだ掃除そうじしていません。
※ まだ ＋ 掃除していません。
R-8. Say in casual Japanese using 〜とく: 'I'll book the restaurant in advance!' (レストランを予約よやくしておくね)
レストランを予約よやくしとくね！
※ 予約しておく → 予約しとく！
