# JLPT教材・演習アプリ作成 完全標準ガイドライン (JLPT Page Builder Specification)

本ドキュメントは、JLPT（N1〜N5）の**問題データ、フラッシュカード、穴埋め・文法演習道場、辞書連携**を新規作成・改修する際に**必ず遵守すべき絶対ルール**です。ユーザーから過去に受けた指摘・修正改善要望を100%漏れなく体系化しており、他レベル（N1, N3, N4, N5等）の制作時にも本ルールを自動適用し、手戻りや指摘の再発を完全に防止します。

---

## 1. ホーム画面・ページ間ナビゲーションの絶対ルール

1. **アプリのホームは `app.html`（総合ポータル画面）であること**
   - 「ホームに戻る」ボタンを押した際、フラッシュカード画面や演習画面へ遷移させてはならない。必ず `app.html` に戻す。
2. **絵文字ファイル名（`📱_日本語学習アプリ.html` 等）へのリンク禁止**
   - GitHub Pages や一部のWebサーバー環境で404 Not Foundエラーとなるため、リンク先は必ず半角英数字の `app.html` に統一する。
3. **相互リンクの完備**
   - 演習道場 ⇔ フラッシュカード ⇔ 総合演習ポータル（`jlpt_practice.html`）への行き来を常にワンタップで可能にする。

## 2. 音声読み上げ（TTS）の絶対ルール（ルビ2重読み上げ防止）

ユーザーから最も厳しく指摘された重大バグです。**すべての音声再生関数で例外なく以下の前処理を実装すること**。

### 🚨 2重読み上げの原因と完全防止コード
HTMLタグ `<ruby>大雨<rt>おおあめ</rt></ruby>` を単に `replace(/<[^>]+>/g, '')` すると、`大雨おおあめ` と漢字とルビが連続結合し、音声エンジンが「大雨」と「おおあめ」を2回連続で発音してしまう。

```javascript
// ✅ 正しい音声テキスト抽出処理（必ず <rt>...</rt> を先に消す）
function extractSpeechText(htmlText) {
  if (!htmlText) return '';
  return String(htmlText)
    .replace(/<rt>[\s\S]*?<\/rt>/gi, '') // 1. ふりがな部分を完全除去
    .replace(/<[^>]+>/g, '')             // 2. 残りのHTMLタグを除去
    .replace(/（\s*）|\(　*\)|（　*）/g, '、') // 3. 空欄は自然な一呼吸（読点）に置換
    .replace(/（する）|\(する\)/g, '')   // 4. 不要な品詞カッコを除去
    .replace(/[【】]/g, '')               // 5. 強調カッコを除去
    .replace(/\s+/g, ' ')                // 6. 連続空白を1つに整理
    .trim();
}
```

### 🔊 音声再生エンジンのハイブリッド設計
- 単語単体の発音は、多音字の誤読を防ぐため **`reading`（ひらがな）を最優先** で渡す。
- 例文・問題文は、上記の `extractSpeechText()` を通した**自然な漢字かな交じり文**を渡す（文脈アクセントが最も自然になるため）。
- **Google TTS API（高音質）を優先** し、通信制限やブロック時は **Web Speech API（SpeechSynthesisUtterance）に自動フォールバック** させる。

## 3. 問題文・例文の品質 & OCR文字化けの絶対根絶ルール

1. **OCR欠落・誤認識の完全排除**
   - 「食できたのは」➔ 「合格できたのは」
   - 「太学に食べ」➔ 「大学に合格」
   - 「新しい企画のウイルスについて…」のような機械的テンプレート文は禁止。**100%自然な実生活・JLPT本試験に即した日本語文**にする。
2. **問題文への選択肢混入（ベタ貼り）の禁止**
   - 例: 「家族の協力をめぐって私の成功はなかった」のように、空欄 `（　　　）` が消えて正解が問題文に最初からネタバレ混入している不具合を絶対に起こさないこと。
3. **空欄の表記統一**
   - 空欄の中に「？」や「【空欄】」「【 空欄 】」などの不要な文字を入れない。
   - 必ずすっきりした **`（　　　）`**（全角スペース3つ程度）で統一する。
4. **不要な「（する）」の根絶**
   - 問題文「今月のしょうひ（する）」等の不自然な（する）は完全に消す。
   - 語彙カードの `reading` 欄に「あいず（する）」と入れない（表示時に `（あいず（する））` と二重カッコになるため）。`reading` は純粋な平仮名「あいず」にする。

## 4. ルビ（ふりがな）の多音字・誤変換防止チェックリスト

自動ルビ振りツールが誤りやすい頻出パターンを必ず精査すること：

| 漢字 | 誤りやすい例 | 正しいルビ | 判定基準 |
| :--- | :--- | :--- | :--- |
| **開** | 穴が開（**ひら**）き | 穴が開（**あ**）き | 穴・ドア・目・口・鍵・封筒が開く ➔ 「あく／あける」 |
| **開** | ドアを開（**ひら**）けた | ドアを開（**あ**）けた | 会議・会・バザーを開く ➔ 「ひらく」 |
| **降** | 雨が降（**お**）り出しそう | 雨が降（**ふ**）り出しそう | 雨・雪・陽射しが降る ➔ 「ふる／ふり」、吹き降り ➔ 「ふきぶり」 |
| **降** | 電車を降（**ふ**）りる | 電車を降（**お**）りる | 乗り物から降りる ➔ 「おりる」 |
| **入** | 部屋に入（**いっ**）て | 部屋に入（**はい**）って | 部屋・風呂・ベッド・耳・頭に入る ➔ 「はいる／はいって／はいった」 |
| **入** | 聞き入（**はい**）った | 聞き入（**い**）った | 聞き入る・聴き入る ➔ 「ききいる／ききいった」 |
| **辛** | 人気者は辛（**から**）い | 人気者は辛（**つら**）い | 精神的・肉体的につらい ➔ 「つらい」、味覚 ➔ 「からい」 |
| **空** | 席が空（**そら**）いた | 席が空（**あ**）いた | 空席・穴が空く ➔ 「あく」、お腹が空く ➔ 「すく」、大空 ➔ 「そら」 |

## 5. 解答ネタバレ防止ルール（漢字表記問題）

- **「ひらがな ➔ 漢字」を選ぶ表記問題において、選択肢にふりがな（ルビ）をつけてはならない**。
  - 生徒が漢字を読めなくてもルビを見て正解を選べてしまうため、ネタバレになる。
  - 漢字表記問題（表記・漢字選択）では、選択肢は必ず **プレーンな漢字（ふりがな非表示）** にすること。

## 6. UI・レイアウトの最適化ルール

1. **選択肢レイアウトの動的切り替え**
   - 用法問題や短文選択肢など、選択肢の文字数が多い（15文字以上または読点・句点を含む）場合は、2列表示で折り返して行が崩れるのを防ぐため、**1列・4行（1行1文）** の縦並びレイアウトを自動適用する。
2. **フラッシュカードのランダム実力テスト機能**
   - フラッシュカード画面には必ず **「⚡ 10問」「🔥 30問」「🏆 50問」** のクイックテストピルボタンを常設する。
   - 出題範囲は「全単語」と「現在のカテゴリ」をワンクリックで切替可能にする。
   - テスト中はリアルタイムプログレスバー（例: `3 / 10問`）と正解数バッジを表示。
   - テスト完了後は **リザルト画面（スコア、定着率%、要復習単語リスト、要復習のみ再特訓ボタン）** を提供する。
3. **キーボード操作 & スワイプ操作**
   - フラッシュカード：`Space`/`↑`/`↓`でカードめくり、`←`/`→`で前後の単語、`1`でもう一回、`2`で覚えた。
   - スマホの左右スワイプ対応。

## 7. 新規レベル・新規ページ作成時の事前チェックリスト

新規にJLPTのページ（N1, N3等）を作成・公開する前に、以下のスクリプト検証を自動実行すること：

- [ ] **構文チェック**: `osascript -l JavaScript` 等で本番JavaScriptエンジンによるコンパイルエラー 0 件を確認。
- [ ] **リンク切れチェック**: `href` に存在する全HTMLファイルの実在を確認。絵文字ファイル名が含まれていないことを確認。
- [ ] **正解整合性チェック**: 全問題の `choices[answer] === correct_text` が 100% 一致していることを確認。
- [ ] **選択肢重複チェック**: 4つの選択肢の中に重複がないことを確認。
- [ ] **音声テスト**: `extractSpeechText()` を経由して `<rt>` が完全に除去されていることを確認。
- [ ] **空欄表記チェック**: `（　　　）` 以外の「？」「空欄」文字が残っていないことを確認。
